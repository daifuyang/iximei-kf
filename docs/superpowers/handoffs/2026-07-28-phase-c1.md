## 4. Fix Round 原因 + 解决方式

### 4.1 T2 fix round（commit `e103368`）

**原因**：plan `task-2-brief.md` 写的 `assertHospitalAccount(userId, roleIds)` 签名是错的。implementer 主动 grep 仓库，发现真实签名是 `(roleIds, action)`，且 helper ternary 当时只处理 2 case（`'stats'` / `'unviewed-count'`）不覆盖 `'trend'`。

**解决**：
- 扩展 ternary 为 4-way：`'stats'` / `'unviewed-count'` / `'trend'` + 未知 action fallback
- 新增 `emptyDaily(days)` module-level helper（仿 `getTrend` repo 日期窗口逻辑），无医院绑定账号的安全 fallback
- service `getTrend(userId, roleIds, days = 30)` 签名与既有 `getStats` / `getUnviewedCount` 风格一致

**亮点**：subagent 严格按 plan「不照搬」约定主动 escalate，避免了 Phase B 那种「brief 错就照搬」浪费一个 fix round。✅ Re-review ADDRESSED, Approved。

### 4.2 T4 fix round（commit `2e5cdcd`）

**原因**：T4 初版 (`d8e9877`) 用了 antd-charts v1 API：`xAxis` / `yAxis` / `showCrosshairs` / `smooth` (bool) / `tickInterval` / `label.type='inner'` + `label.content='{percentage}'` / `legend.position`。但 `apps/yishan-admin/package.json` 安装的是 `@ant-design/charts 2.6.7`，其 plot API 是 v2 G2 Spec —— 上述 props 全部不存在或形态不同。

**解决**：完全替换为 v2 G2 Spec：
```tsx
// Line
<Line axis={{ x: { title: '日期' }, y: { title: '派单数' } }}
       shapeField="smooth" point={{ shapeField: 'circle', sizeField: 4 }}
       style={{ stroke: '#1677ff', lineWidth: 2 }} ... />

// Pie
<Pie angleField="value" colorField="type"
     label={{ position: 'inside', text: (d) => `${百分比}%` }}
     legend={{ color: { position: 'bottom' } }} ... />
```

**未触动**：数据流 / 布局 / 降级 / retry handler / `useState`/`useEffect` 结构 / `filter value > 0` —— 全部保留 R2/R3 设计。

✅ Re-review F1+F2+F3 ADDRESSED, Approved。
